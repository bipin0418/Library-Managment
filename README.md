# Library Management System in C

This is a simple Library Management System made using the C programming language.  
The project stores book records in a CSV file using file handling concepts.

## Features

- Add new books
- View all books
- Search book by ID
- Delete book records
- Store data in CSV file

## Technologies Used

- C Programming
- File Handling
- CSV File Storage
